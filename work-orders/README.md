# Work Orders

minimum contract (immutable ID, objective, acceptance criteria, owner and
routing rationale, exact repository/ref/paths/exclusions, base commit and
dirty-state assessment, dependencies, deliverables and content digest,
validation commands, approval boundaries, response window, stop conditions,
handoff destination). Empty until Agent Zero authorizes an assignment.
